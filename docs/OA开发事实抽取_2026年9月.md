## 五、安全与生产化事实

| 项 | 事实 | 来源 |
|---|---|---|
| **CORS** | 显式来源，`cors_origins` 逗号拆分 → `cors_origin_list`，`allow_credentials=True`，**生产禁用通配符** | HARDENING.md、backend/app/core/config.py |
| **限流** | `RateLimitMiddleware` 固定窗口（每分钟每 IP），`rate_limit_per_minute=0` **默认关闭**；探针/文档路径豁免；429 带 `Retry-After` | HARDENING.md、backend/app/core/middleware.py、backend/app/core/config.py |
| **PBKDF2 迭代** | `hashlib.pbkdf2_hmac` + sha256，`_PBKDF2_ITERS = 600_000`（**60 万，对齐 OWASP**，由 10 万上调）；哈希串自带迭代次数，`verify_password` 按串内次数校验，**向后兼容** | backend/app/core/security.py、项目开发工作总结_2026年9月.md |
| **令牌时效** | 访问令牌 **15 分钟**；刷新令牌 **7 天**，服务端 `refresh_tokens` 表存储、可吊销、登录时轮换；签发加 `jti=uuid4` 防同秒唯一索引冲突 | README.md、backend/app/core/config.py、docs/评估报告-2026-09-28.md |
| **安全头** | `X-Content-Type-Options: nosniff`、`X-Frame-Options: DENY`、`Referrer-Policy: no-referrer`、`Content-Security-Policy: default-src 'self'` | HARDENING.md、backend/app/core/middleware.py |
| **SSE** | `GET /api/events/stream`，`get_current_user` 鉴权；心跳 `sse_heartbeat_seconds=25`；下发 `X-Accel-Buffering: no`；**令牌仅走 Authorization 头不入 URL**；前端 `fetch`+`ReadableStream` 手动解析（`EventSource` 无法带 Authorization），断线指数退避重连；事件总线为进程内 asyncio pub/sub，慢消费者丢弃最旧事件 | HARDENING.md、backend/app/api/realtime.py |
| **死信** | `scheduler_dead_letters` 表；审批超时升级失败写死信且不计升级，下轮自然重试；幂等边界 `escalated_at IS NULL` + 标记后仅通知一次 | PHASE5_TEST_OVERVIEW.md、DELIVERY.md |
| **优雅停机** | `ActiveRequestMiddleware` 在途请求计数 + `main.py` lifespan drained 等待，超时默认 **15s** | HARDENING.md、backend/app/core/middleware.py |
| **审计** | `AuditMiddleware` 自动审计所有变更类请求 + 登录/登出/刷新；按路径语义标注 module/action/target；独立事务、失败只告警；`detail` 脱敏，**绝不写密码/令牌/签名图像** | P3_LOG_CENTER.md |
| **Docker** | 3 服务：`postgres:16-alpine`（带 healthcheck，后端等它 ready）+ `backend`（启动前自动 `alembic upgrade head`）+ `frontend`（多阶段 Node 构建 → `nginx:alpine` 托管，宿主 5173→容器 80） | docker-compose.yml、README.md |
| **CI** | `.github/workflows/ci.yml`，push/PR 触发，后端与前端**并行**两 job | .github/workflows/ci.yml |
| **上传安全** | 单文件 ≤ 20MB；扩展名白名单（pdf/doc/docx/xls/xlsx/ppt/pptx/png/jpg/jpeg/gif/txt/zip/csv/md）；落盘 `{id}.{ext}` **绝不用客户端文件名拼路径**；下载走鉴权端点，`file_url` 仅存逻辑地址 | P4_CONTENT_ENGINE.md |
| **生产快速失败** | `ENVIRONMENT=production` 时弱 JWT 密钥或 SQLite 直接启动报错退出 | HARDENING.md、backend/app/core/config.py、DEPLOYMENT.md |
| **存储抽象** | `local` 磁盘 / `s3` 签名 URL 自动切换（aioboto3），`file_url` 逻辑地址不变 | DELIVERY.md、P4_CONTENT_ENGINE.md |
| **可观测** | 结构化 JSON 日志 + `request_id` 链路 ID（支持 `x-request-id` 透传）；审计含 `correlation_id` / `duration_ms` | HARDENING.md、P3_LOG_CENTER.md |
| 未落地（运维配合） | HTTPS/TLS 终止依赖 Nginx/云 LB；刷新令牌 httpOnly Cookie 化建议升级；限流默认关闭待调参 | HARDENING.md、DEPLOYMENT.md |
